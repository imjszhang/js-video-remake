**video-remake 是一个本地视频制作与对标复刻工作台。** 导入模板，换上自己的素材，合成视频；用自然语言让 Agent 改造场景与动画；围绕参考原片完成制作、对比和交付。

提供网页界面和命令行。视频在本机渲染，模型和素材服务按需接入。

> **当前版本：0.1.0 · 测试版。** 核心流程仍在迭代，接口、模板格式和配置可能调整。使用前请备份本地制作数据。查看[更新记录](CHANGELOG.md)与[版本约定](docs/versioning.md)。

## 为什么用 video-remake

- **🎬 从模板到成片** — 替换人物、声音、字幕和个人信息，检查、预览、合成 MP4。
- **💬 用语言改造画面** — 描述你想要的布局、风格与动画，让 Agent 修改模板源码并生成预览。
- **🔍 参考与作品放在一起** — 管理原片、关联制作，同步播放对比，也能导出对比视频。
- **📦 把作品沉淀成模板** — 导出 `.video`，别人可独立填写素材并合成，继续复用你的设计。
- **🗂️ 每次修改保留版本** — 已登记的代码视频包冻结，后续修改开新版本，保留草稿与来源记录。

## 功能一览

| 你想做的事 | 项目提供的功能 |
| --- | --- |
| 用现成模板做自己的视频 | 导入 `.video`，填写个人信息、替换人物录像、口播、配乐和文字，预览后合成 MP4 |
| 用自然语言修改模板 | 让已配置的 Agent 修改场景、布局、风格和动画，检查结果并生成静态预览，支持继续迭代 |
| 编辑字幕和准备口播 | 逐句编辑中英字幕；上传录音，或在 macOS 上按字幕时间窗生成系统语音口播 |
| 管理参考视频 | 导入本地视频或清单、扫描文件夹、从链接下载，查看原片可用状态及关联制作 |
| 复刻、审阅和交付 | 建立制作工程，准备素材，渲染版本；网页同步对比原片，也可导出竖屏对比视频和正式成片 |
| 分享可复用模板 | 导出 `.video`，接收者可独立解压、填写素材并合成，无需安装本工作台 |
| 研究自动复刻方法 | 在高级「AI 复刻实验」中提炼方法配方，让执行模型生成工程，再进行技术检查与评审 |

几个概念：**参考视频**是用来分析和对比的原片；**制作**是一次创作的项目目录；**模板**包含可复用的画面和时间轴；**成片**是填好素材后渲染出的 MP4。一个制作可保留多个模板及版本。

## 快速开始

准备 Node.js **22.15.0 或更新版本**：

```bash
git clone https://github.com/imjszhang/js-video-remake.git
cd js-video-remake
npm ci
npm start
```

打开 [http://127.0.0.1:8786/](http://127.0.0.1:8786/)。无需单独构建前端，默认只监听本机。首次克隆是空工作区，需要自行导入模板或参考视频。

| 使用场景 | 额外准备 |
| --- | --- |
| 合成视频、渲染预览与对比片 | FFmpeg / ffprobe，以及 HyperFrames 所需浏览器；HyperFrames `0.8.191` 由依赖锁定 |
| 从链接下载参考视频 | 本机 yt-dlp，见[下载配置](docs/local-references.md#从链接下载并登记) |
| 让 Agent 改造模板 | 配置并启用本机 Agent，见[Agent 配置](docs/agent-runtime.md#配置与首次运行) |
| 生成图片、视频片段或转写 | 所选服务或本机工具，见[素材生成配置](docs/media-providers.md) |
| 按字幕生成本机口播 | macOS、已安装的系统音色、FFmpeg / ffprobe，见[口播说明](docs/template-speech.md) |

使用默认设置即可启动工作台。需要修改素材目录、下载工具或素材服务时，再从 `video-remake.example.json` 复制一份为 `video-remake.json` 并编辑；已有配置请直接修改。配置文件仅保存在本机。

端口、远程访问、macOS 常驻服务及反向代理配置见[工作台与部署](docs/workbench.md)。

## 选择你的制作流程

### 1. 已有模板：填入素材，合成视频

这是从现成模板开始的最短流程，无需先绑定参考视频，也无需配置 Agent。

1. 在「制作工作台」点击「导入模板」，选择 `.video` 文件，打开新建的制作。
2. 进入「模板工作台」的「填写素材」，填写个人信息、修改字幕，按模板需要上传人物录像、口播或配乐。
3. 点击「准备录制稿」，按每句话的时间安排准备录音；也可在 macOS 上根据当前字幕生成口播。首次准备会自动安装包内锁定依赖。
4. 点击「检查素材」，处理错误；在「预览与导出」生成静态截图，查看画面和文字。
5. 点击「合成可播放视频」。完成后到「成片放映」播放或下载 MP4，合成结果会自动登记为草稿。

**静态截图用于检查画面，合成才会产生可播放视频；「导出 .video 模板」得到的是可复用模板包。** 已合成的版本会冻结，继续修改时选择「复制为新版本继续编辑」。

填写素材沿用模板固定的字幕条数与时间轴。人物画面在人物窗内静音播放，声音来自口播和配乐；人物录像也可以被选为口播来源。未提供可选素材时按模板规则使用占位画面或默认配乐，具体以素材检查结果为准。

完整操作见[网页填写、预览与合成](docs/video-template.md#网页填写预览与合成)；不使用本工作台时见[模板独立使用](docs/video-template.md#独立使用)。

### 2. 想改模板：描述要求，让 Agent 修改

先导入或选择一个模板，并按 [Agent 执行说明](docs/agent-runtime.md) 配置可用目标。示例配置中的目标默认禁用，需主动启用并准备对应登录或密钥。

1. 进入「模板工作台」→「改造模板」，选择「创建新模板」，填写名称和修改要求，例如：“保留内容结构，改成简洁的产品发布会风格，增加标题留白。”
2. 选择可用的 Agent 和模型，启动生成。Agent 修改模板源码后，系统会构建、检查并生成静态预览。
3. 查看结果；继续修改同一模板时选择「迭代当前模板」。新模板从 v1 开始，同一模板迭代为 v2、v3，保留来源关系。
4. 满意后导出 `.video`；需要成片时，再按上面的流程填写素材并合成。

生成新模板会实际调用模型，不携带上一版填写的个人信息和上传素材，也不会自动渲染完整视频。来源模板需先创建衍生模板，才能迭代。执行能力与权限由所选 Agent 配置决定，外部 Agent 不继承当前聊天或 MCP 插件。

详细操作与命令见[用提示词生成新模板](docs/video-template.md#用提示词生成新模板)。

### 3. 想复刻参考视频：建立制作，渲染并对比

1. 在「参考视频」→「添加参考」导入本地文件或清单、扫描文件夹，或从链接下载。填写本地路径时，使用运行工作台那台设备上的路径。
2. 从参考创建制作，记录制作目标、参考分析和分镜安排。同一条参考可用于多份制作。
3. 自己或让 Agent 创建并编写代码视频包，准备所需图片、视频、声音和字幕，再检查、预览、渲染。
4. 将渲染结果登记为草稿，在「成片放映」中与原片同步对比；需要分享对比结果时导出竖屏对比片，确认后登记正式交付。

创建制作只建立目录和记录，创建视频包只提供工程起点；原片分析、场景编写和素材准备仍需完成。命令行步骤见[制作工程、渲染与交付](docs/production-workflow.md)。

需要模型自动执行和评审时，展开「高级功能」→「AI 复刻实验」（`/repro`）。它使用单独配置的方法配方、任务规格、输入和模型角色，从空工程生成场景，再做技术检查与双评审。完整流程见[方法配方与独立制作](docs/reproduction.md)。

## 使用前了解

- **原片只读引用。** 本地导入、扫描只登记原文件路径，不复制或移动原片；原文件需要继续保留。链接下载是单独操作，默认使用 yt-dlp。参考清单默认使用本地数据，无需素材网关在线。
- **版本与输出可追溯。** 代码视频包登记为草稿时记录源码与文件哈希；已登记的包冻结，修改需开新版本。网页展示台账指向的当前草稿、交付与对比，历史文件仍保存在磁盘。模板版本不等同于成片版本。
- **网页对比与导出对比不同。** 网页按相同秒数同步播放原片和复刻版，短片结束后保留尾帧；导出的竖屏对比片需指定共同播放范围，不自动拉伸时长。详见[对比导出](docs/production-workflow.md#竖屏对比预览)。
- **素材服务按需接入。** 默认出图为 Codex 内置生图、视频片段为 ComfyUI MCP、转写为 MLX Whisper；前两者由 Agent 调用工具。另有可选 API 适配器，部分只通过模拟测试，具体支持范围与验证状态见[素材生成](docs/media-providers.md)。使用生成服务前需配置对应工具并明确授权费用。
- **模板填写遵循固定时间轴。** 改字幕后需重新录制或生成匹配的口播；改变分句、时长或场景结构应进入模板改造流程。本机口播使用系统音色，不克隆人物声音。
- **自动复刻需要评审。** 技术检查通过不代表视觉还原达标。方法配方的独立生成与历史完整工程回放分别记录，回放不计为独立生成。

## 本地数据与开发

Git 仓库保留程序、测试、通用文档、工具资源和示例配置。`productions/`（包括制作源码）、`references/`、`deliverables/`、`assets/`、`reproductions/` 中的实际工作数据，以及 `catalog.json`、`sources.json`、本地配置和 `.env*` 仅保存在本机，不提交。克隆仓库不会带上已有作品；需要保留作品时应另行备份本地工作数据。取消 Git 跟踪不会删除本地文件，也不会清除历史提交中的旧内容。

Agent 指南统一维护在 `.agents/skills/`，其他 Agent 目录通过软链接引用：`remake-media` 负责素材生成与落地，`remake-references` 负责参考与制作关联查询，`video-template` 负责使用模板并随 `.video` 分发。

开发约定见 [AGENTS.md](AGENTS.md)。依赖使用 `npm ci` 按锁文件安装；完整回归运行：

```bash
npm test
```

测试使用模拟服务，不访问网络，不调用真实生成服务。

### Web 项目归档

在项目页右上角的「⋯」菜单中选择「归档项目」，可从「进行中」列表隐藏项目。左侧切换到「已归档」可找到它，在同样的菜单里选择「恢复项目」即可恢复。归档状态会保存，素材、模板和成片不会删除。

左侧「我的制作」标题旁的「＋」随时回到制作库，开始新的制作或导入模板。
