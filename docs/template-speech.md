# 模板字幕生成本机口播

自动口播使用 macOS 自带的系统语音，不需要云服务账户或 API Key，也不会把字幕发送到外部模型服务。需要本机安装 FFmpeg 和 ffprobe。音色列表只显示系统已经可用的中文与英文音色；缺少音色时，可以先在 macOS 系统设置中安装。

输入是当前模板的有效中英字幕、固定的起止时间，以及已填写的个人信息。生成中文时使用 `zh`，生成英文时使用 `en`；`{{name}}`、`{{badge}}` 等身份占位符会替换为个人信息中的实际值，未填写的变量会提示具体句号。英文空句会跳过，其时间段保持静音；整份所选语言都没有文字时不会生成空口播。

系统逐句生成语音，并把每句放回原字幕时间窗。句间空白和结尾自动补静音，输出是与模板全片等长的 48 kHz、单声道 PCM WAV。某句略长时自动加速；加速上限为 3 倍，仍装不进时间窗时会指出具体句号，请缩短文字再生成。它不会修改字幕内容、字幕时间或模板源码，也不会克隆人物声音。

生成过程支持逐句进度和取消。取消或失败后清理临时文本与音频，不留下半成品；输出使用新文件，不覆盖既有口播。文字通过私有临时文件输入语音工具，`[[...]]` 形式的语音控制指令被移除定界符，避免字幕内容改变语音工具行为。

程序接口位于 `src/template-speech.js`：

- `speechOptions(config, deps)` 返回提供方、可用状态、音色及默认音色；这是只读检测。
- `synthesizeCaptionSpeech(config, {rows, identity, voice, language, duration, outputFile}, deps)` 生成整片口播。`rows` 包含 `start`、`end`、`zh`、`en`，`outputFile` 是尚不存在的绝对路径 WAV 文件，父目录由调用方准备。
- 子进程统一经 `deps.runSpeechCommand` 注入；`deps.signal` 负责取消，`deps.onProgress` 接收阶段、当前句号和进度。测试使用模拟语音与 FFmpeg，不调用真实生成。
